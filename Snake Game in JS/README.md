# Snake Game in JS

A small, classic Snake game implemented with plain HTML, CSS and JavaScript.

## Files
- `index.html` — game shell and canvas container
- `script.js` — game logic and input handling
- `style.css` — styles and layout

## How to run
1. Open `index.html` in your web browser.
2. Or run a simple HTTP server from the project directory:

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## Controls
- Arrow keys (← ↑ → ↓) or `W`/`A`/`S`/`D` to move the snake

## Objective
Eat food to grow the snake. Avoid colliding with the walls or yourself.

## Customization
- Adjust speed, grid size, and colors in `script.js` and `style.css`.
